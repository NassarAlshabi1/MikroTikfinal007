# إدارة وتقارير كروت User Manager

دُمج مدخل **مزامنة كروت اليوزرمنجر** ومدخل **تقرير الكروت** في شاشة واحدة: **إدارة وتقارير كروت اليوزرمنجر**. تعرض الشاشة كروت User Manager وتحتفظ بإجراءات الإدارة والبحث والتحديد والنسخ، وتضيف إليها تصنيفات المستخدمة والمنتهية وتصدير هذه التقارير بصيغتي CSV وPDF. تصدير التقرير متاح بعد اختيار تصنيف المستخدمة أو المنتهية، وليس لتصدير كل كروت الإدارة.

## مصدر الحالة والانتهاء

- تُقرأ البيانات من `/tool/user-manager/user/print` فقط.
- تُحسب البطاقة مستخدمة من قيمة `uptime-used` الموجبة.
- يُلتقط تاريخ الانتهاء من أول حقل غير فارغ بالترتيب: `expires` ثم `expiration` ثم `end-time` ثم `valid-until`. التاريخ الأقدم من اليوم يعد منتهياً؛ يبقى تاريخ اليوم صالحاً حتى نهايته.
- تبقى قواعد الانتهاء السابقة: تعطيل المستخدم أو استهلاك حد `uptime-limit`/`limit-uptime` يعدّ البطاقة منتهية أيضاً.
- إذا غابت قيمة `uptime-used` أو تعذر تحليلها، لا تُحتسب البطاقة مستخدمة، وتعرض الشاشة تنبيهاً بعدد القيم غير المعروفة.

## التصدير والتنقل

يصدر CSV وPDF الصفوف المطابقة للبحث والمرشحات الحالية، مع ملخص المزامنة وحالة الاستخدام وتاريخ الصلاحية. لا تُصدّر كلمات المرور أو التعليقات أو معرّفات الراوتر، ولا تُنشأ أسعار أو إيرادات غير موجودة في User Manager.

أزيل مدخل الشاشة المنفصلة من القائمة الرئيسية وأصبحت إمكانات التقرير ضمن شاشة الإدارة نفسها. لا يلزم ترحيل بيانات؛ التغيير يخص التنقل والعرض فقط، وبنية التقرير ومصدّر CSV/PDF ما زالا مستخدمين من الشاشة الموحّدة.
