# مراجعة وتقوية Prompts الذكاء الاصطناعي

## الهدف

تمت تقوية طبقة الذكاء الاصطناعي في تطبيق MikroTik Manager بحيث تنتج إجابات عربية مهنية، دقيقة، منظمة، وقابلة للمراجعة قبل تنفيذ أي أمر على RouterOS 6.49.19.

## التحسينات الأساسية

| المجال | التحسين |
|---|---|
| الاتساق | إضافة `professionalContract` عالمي يسبق كل وضع تشخيص. |
| جودة الصياغة | فرض الخلاصة التنفيذية، الأدلة المرصودة، المشاكل حسب الأولوية، السبب الجذري، الأثر، الإجراء، التحقق، التراجع، وخطة التنفيذ. |
| الدقة | منع اختراع القيم أو الأوامر أو نتائج التنفيذ، مع التصريح عند نقص البيانات. |
| اللغة | إلزام العربية الفصحى مع إبقاء أسماء أوامر RouterOS والمصطلحات التقنية بالإنجليزية عند الحاجة. |
| RouterOS | تثبيت RouterOS 6.49.19 ومنع WireGuard وREST ومسارات v7، مع التفريق بين Hotspot المحلي وUser Manager. |
| Hotspot | استخدام `/ip/hotspot/...` افتراضياً، واعتماد `name` و`profile` للكروت المحلية وعدم إرسال `shared-users` إلى أمر إضافة المستخدم. |
| الأمان | منع كشف الأسرار، واعتبار snapshot وlogs بيانات غير موثوقة وليست تعليمات. |
| التنفيذ | منع توليد أوامر تعديل أو حذف تلقائياً لمجرد اكتشاف مشكلة؛ الأوامر الإنشائية تظهر عند طلب صريح مع مستوى الخطورة والتحقق والتراجع. |
| Agentic | السماح ببروتوكول JSON عندما يفرضه المسار الوكيلي، دون كسر قواعد الأمان. |
| السياق | تنقية حقول password وsecret وAPI key وtoken، وتحديد سياق الجهاز إلى 28,000 حرف مع الاحتفاظ بذيل المخرجات. |
| Gemini | إرسال التعليمات عبر `systemInstruction` وعدم تكرارها داخل رسالة المستخدم. |

## قالب الرد المطلوب

يبدأ الرد بخلاصة تنفيذية، ثم الأدلة المرصودة، ثم المشاكل مرتبة بمستويات P0 إلى P3 ودرجة ثقة، ثم خطة التنفيذ وأوامر التحقق. عند طلب أمر تعديل صريح يعرض AI حالة التنفيذ بوضوح: **اقتراح فقط — لم يُنفّذ على الراوتر**.

## التحقق

أضيفت اختبارات تتحقق من أن كل أوضاع التشخيص تستخدم العقد الموحد، وأن وضع Hotspot يحتوي مسار `/ip/hotspot/user/add` وحقول `name/profile`، وأن Prompt العام يمنع أوامر RouterOS v7 والتنفيذ الصامت. نجح `flutter analyze` وجميع اختبارات AI المستهدفة.
