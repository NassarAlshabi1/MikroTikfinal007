## 📖 نبذة عن النظام

**ميكرونت (MikroNet)** هو نظام متكامل لإدارة شبكات MikroTik من هاتفك بسهولة واحترافية، يجمع بين إدارة المستخدمين، إنشاء الكروت، المحاسبة، مراقبة الشبكة، وإدارة المبيعات في تطبيق واحد باللغة العربية.

سواء كنت تدير شبكة **Hotspot** أو **User Manager** أو **PPPoE**، يمنحك ميكرونت الأدوات التي تحتاجها لإدارة شبكتك بشكل أسرع وأسهل.

## 🔥 أهم مميزات ميكرونت

### 👥 إدارة المستخدمين والهوتسبوت واليوزر مانجر

- إدارة مستخدمي Hotspot ومتابعة حالة الكروت.
- معرفة المستخدمين النشطين والمستخدمين والمنتهية صلاحيتهم وغير المرتبطين بالباقات.
- إدارة User Manager والتحكم بالحسابات والباقات والمستخدمين.
- إدارة اشتراكات PPPoE / Broadband.
- إنشاء وتعديل وحذف المستخدمين والباقات.
- متابعة استهلاك المستخدمين والبيانات ومدة الاتصال.
- التحكم المباشر براوتر MikroTik عبر API.

**داخل التطبيق:** `المستخدمون` ← *النشطون* / *المحفوظون* / *Host*، مع صفحات *الباقات* و*البطاقات*.

### 🎫 إنشاء وطباعة كروت الشبكة

- إنشاء كرت واحد أو آلاف الكروت بسهولة.
- تصدير وطباعة كروت الشبكة.
- تصميم قوالب خاصة للكروت.
- استخدام قوالب جاهزة للطباعة.
- إضافة الصور والشعارات وبيانات الشبكة إلى تصميم الكرت.

**داخل التطبيق:** `الطباعة` ← *الدفعات* (Batches) / *القوالب* (Templates) / معاينة PDF، مع تخزين القوالب محليًا (SQLite).

![نموذج كرت شبكة](images/100.jpg)

### 💰 المحاسبة والمبيعات والأرباح

- متابعة مبيعات الكروت اليومية والشهرية.
- معرفة إجمالي المبيعات والأرباح.
- إدارة نقاط البيع والموزعين.
- متابعة حساب كل موزع دائن / مدين.
- تقارير مالية ومحاسبية مفصلة.
- تصدير تقارير PDF لكل موزع أو نقطة بيع.
- تنظيم الحسابات دون الحاجة إلى دفاتر خارجية.

**حذف المستخدمين المنتهين (فحص ذكي):** يقارن المدة المستهلكة `uptime-used` مع حد الباقة
`limit-uptime` ويحذف **فقط** من استهلك مدته كاملة، مع تحليل صحيح لصيغ RouterOS مثل `1w2d3h4m5s`
و`1w2d03:04:05`. أي صيغة غير مفهومة تُستبعد من الحذف بدل تخمينها، ويمكن إضافة من انتهى رصيد بياناته فقط كخيار.

**داخل التطبيق:** `إدارة الكروت` ← *المستخدمون المنتهون*، و `المزيد` ← *الموزعون والمحاسبة* (أرصدة دائن/مدين، أرباح، كشف حساب PDF لكل موزع)
و `التقارير` ← *تقرير المبيعات* / *تقرير حالة النظام*.

### 📊 مراقبة الراوتر والشبكة

- متابعة حالة الراوتر لحظة بلحظة.
- مراقبة استخدام CPU.
- مراقبة RAM والذاكرة.
- متابعة درجات حرارة الراوتر.
- مراقبة حركة البيانات واستهلاك الإنترنت.
- متابعة المنافذ Ports / Interfaces.
- معرفة الأجهزة المتصلة وغير المتصلة بالشبكة.

**داخل التطبيق:** لوحة *الصفحة الرئيسية* (بطاقة حالة النظام) + تقرير *حالة النظام*
+ صفحة *مراقبة الشبكة* (حرارة الراوتر والحساسات، المنافذ، وحركة التنزيل/الرفع لحظيًا كل 6 ثوانٍ).

### 🌐 إدارة صفحات الهوتسبوت

- رفع صفحات Hotspot إلى الراوتر بسهولة.
- قوالب صفحات تسجيل دخول جاهزة.
- تعديل اسم الشبكة.
- إضافة الباقات والأسعار.
- إضافة نقاط البيع وأرقام التواصل.
- تخصيص صفحات الهوتسبوت بما يناسب هوية شبكتك.

**داخل التطبيق:** `المواقع` ← *الحجب* / *ذاكرة DNS* / *إعدادات DNS*.

### 🧰 أدوات الصيانة ولوحة تحكم الميكروتيك

- **أدوات التشخيص:** Ping، اختبار النطاق (Traceroute)، Torch لمراقبة حركة منفذ لحظيًا،
  Fetch لتنزيل الملفات إلى الراوتر، تنقيط الحزم (Sniffer)، وسجل النظام.
- **مراقبة الأداء:** CPU والذاكرة، RouterBOARD، الاتصالات النشطة (Conntrack)،
  المنافذ، الرسوم البيانية (Graphing)، وأجهزة البث (Neighbor).
- **إعدادات الشبكة (IP):** IP Addresses، خادم DHCP وإيجاراته، عميل DHCP، ARP،
  خادم DNS، ومجموعات العناوين.
- **جدار الحماية:** قواعد التصفية، NAT، Mangle، وبروتوكولات Layer7.
- **إدارة النطاق الترددي (Queue):** Queue البسيطة والشجرية وأنواع Queue.

**داخل التطبيق:** `أدوات الصيانة` (من الرئيسية أو المزيد) — لوحة موحّدة بعدّادات مباشرة لكل قسم.

### 💾 النسخ الاحتياطي

- إنشاء نسخة احتياطية للراوتر.
- الاحتفاظ بنسخ احتياطية لإعدادات الشبكة.
- استعادة النسخة الاحتياطية عند الحاجة.

**داخل التطبيق:** `المزيد` ← *نسخ الراوتر الاحتياطي* (نسخة `.backup` أو تصدير `.rsc` على الراوتر ثم تنزيلها/استعادتها)
و *نسخ بيانات التطبيق* (قاعدة بيانات القوالب والراوترات المحفوظة).

### 🔐 الأمان وسهولة الاستخدام

- حماية بيانات الاتصال والحسابات.
- واجهة عربية بالكامل.
- تصميم بسيط وسهل الاستخدام.
- مناسب لأصحاب الشبكات والموزعين والفنيين.
- لا تحتاج إلى خبرة متقدمة لاستخدام الوظائف الأساسية.

## ⚙️ التشغيل والبناء

### المتطلبات

- **Flutter** 3.27 أو أحدث (القناة المستقرة) — [التثبيت](https://docs.flutter.dev/get-started/install)
- **Dart** SDK `^3.5.1`
- **Android SDK** (للبناء على أندرويد)

### خطوات التشغيل

```bash
# 1) جلب الحزم
flutter pub get

# 2) تشغيل التطبيق (جهاز/محاكي متصل)
flutter run

# 3) بناء ملف APK للإصدار — للأجهزة الحديثة فقط (يرفع رقم الإصدار تلقائيًا)
./tools/build_apk.sh
# ما يعادل: flutter build apk --release --target-platform android-arm64 \
#             --build-name=2.0.0.46 --build-number=2046
# لفرض رقم معيّن: ./tools/build_apk.sh 2.0.0.60
# أو لكل معماريات الأندرويد:
flutter build apk --split-per-abi
```

### تحميل ملف APK الجاهز

- **أحدث إصدار (تحميل مباشر بلا تسجيل دخول) — رابط ثابت:**
  [`MikroNet-2.0.0.0-arm64.apk`](https://github.com/NassarAlshabi1/MikroTikfinal007/releases/latest/download/MikroNet-2.0.0.0-arm64.apk)
  (~10 MB) — يشير دائمًا إلى **أحدث إصدار**: [صفحة الإصدارات](https://github.com/NassarAlshabi1/MikroTikfinal007/releases/latest).
  كل إصدار يُرفق أيضًا باسم يحمل رقمه، مثال: `MikroNet-2.0.0.46-arm64.apk`.
- الملف **للأجهزة الحديثة فقط (arm64-v8a)** — لا يعمل على الأجهزة القديمة 32-بت (armeabi-v7a)
  ولا على المحاكيات (x86_64). لبناء نسخة لكل المعماريات: `flutter build apk --split-per-abi`.
- **الإصدار ورقم البناء يرتفعان تلقائيًا مع كل بناء**: كل APK جديد يأخذ
  `versionName = 2.0.0.<N>` و`versionCode = 2000 + <N>` (N = أعلى رقم بناء منشور + 1)،
  والوسم يكون `v2.0.0.0-b<N>`، وبوابة CI ترفض البناء لو لم يطابق الرقم داخل الـAPK.
- لبضع نسخة جديدة: ادفع التزامًا يحمل `[build apk] [publish release]` فيبني CI وينشر.
- لدفع وسم إصدار صريح: ادفع وسمًا يبدأ بـ `v` (مثل `v2.0.0.7`) فيُستخدم رقمه كما هو.

### البناء عبر Docker (بدون تثبيت Flutter محليًا)

يوفر المستودع `Dockerfile` يحتوي Flutter 3.27.2 + Android SDK جاهزَين:

```bash
docker build -t mikronet .
docker run --rm -v "$PWD/build:/app/build" mikronet
# الناتج: build/app/outputs/flutter-apk/app-release.apk
```

> ملاحظة: ملف `.studio.env` يحتوي `STUDIO_URL` الخاص ببيئة التطوير.

## 🔤 الخطوط

التطبيق يستخدم خط **[Cairo](https://fonts.google.com/specimen/Cairo)** من Google Fonts في كل الواجهة
(بستة أوزان: 400/500/600/700/800/900) وفي ملفات PDF المُصدَّرة (كشوف الموزعين وقسائم Hotspot).

- الرخصة: **SIL Open Font License 1.1** — نصّها في `fonts/cairo/OFL.txt`، والاستخدام التجاري مسموح.
- لاستبداله بخط آخر: ضع ملفات TTF في `fonts/` وحدّث قسم `fonts:` في `pubspec.yaml` ثم غيّر
  `fontFamily` في `lib/main.dart` (وخط PDF في `lib/services/*_pdf.dart`).

## 🩺 إذا فشل تسجيل الدخول إلى الميكروتك

اتبع هذه الخطوات بالترتيب:

| الحالة | الحل |
| --- | --- |
| «التطبيق لا يملك صلاحية الاتصال بالشبكة» | ثبّت أحدث إصدار من صفحة Releases (الإصدارات قبل `v2.0.0.0-b37` كانت تفتقد صلاحية `INTERNET` في نسخة الإصدار) |
| «الراوتر رفض الاتصال» | فعّل خدمة API في الراوتر: `/ip service enable api` وتأكد أن المنفذ **8728** |
| تريد منفذًا مخصّصًا (مثل 1300) | في الراوتر: `/ip service set api port=1300 disabled=no` ثم اكتب `192.168.88.1:1300` في خانة العنوان أو **1300** في خانة المنفذ — التطبيق يقبل أي منفذ 1..65535 |
| تحتاج اتصالًا مشفّرًا | فعّل `/ip service enable api-ssl` واستخدم المنفذ **8729** (يُفعّل TLS تلقائيًا)، أو شغّل **مفتاح «اتصال مشفّر»** مع أي منفذ مخصّص |
| «انتهت مهلة الاتصال» | تأكد أن الجوال على نفس شبكة الراوتر وأن عنوان IP صحيح |
| «اسم المستخدم أو كلمة المرور غير صحيحة» | تحقق من بيانات دخول الراوتر (مجموعة `full` مستحسنة) |
| «المستخدم متصل بنجاح لكن صلاحياته غير كافية» | استخدم مستخدمًا بمجموعة `full` في الراوتر |

> الأرقام العربية مقبولة في خانة المنفذ (٨٧٢٨ = 8728)، وأي منفذ غير صالح يُرفض برسالة واضحة بدل الانهيار.
